The owner requested a distinct aesthetic editor rather than Photoshop's default layout, with sophisticated output approachable to a beginner in one or two days.

Start with outcomes: poster, cutout/composite, cleanup, grade and artistic print. Preserve an editable master and reveal exact controls in the same document. No mandatory cloud AI is part of the first-use path. The two-day goal concerns useful workflows, not every specialist discipline.

Atelier is a proposed visual direction, not an approved mockup. Acceptance percentages and latency budgets are proposals, not achieved measurements. See [the system plan](../system/revamp-systems.md).
